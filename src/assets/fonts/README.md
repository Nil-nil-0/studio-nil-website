# Official typefaces

clash/    Clash Display — primary system typeface. The site loads the variable
          file (weights 200–700). The static weights are kept as supplied.
feature/  Feature Display (FeatureDisplay-Regular-Web.1abb9ba9.woff2) — the
          expressive/editorial typeface, weight 400 only.

Registered in src/styles/fonts.css. Do not rename these files.
